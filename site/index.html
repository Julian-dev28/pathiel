PATHIEL

An AI trading agent for Hyperliquid: Claude trades perps from Claude Code, with an exact stop and target on every order.

pathiel is a free, open-source Hyperliquid MCP server and Claude Code plugin: 65 tools that read Hyperliquid perpetual futures markets and your account, and place orders, from Claude Code, Claude Desktop, Cursor or any MCP client.

Real money. pathiel runs on Hyperliquid mainnet. With no key it only reads; once you add a key, orders are real. Practice on testnet with one line: PATHIEL_NETWORK=testnet.

Install in Claude Code

/plugin marketplace add Julian-dev28/pathiel
/plugin install pathiel@pathiel
/pathiel:setup

Setup shows the network and the risks, builds a private Python environment and connects the MCP server. Reading markets needs no account; trading needs a Hyperliquid API wallet, which can trade and never withdraw.

What it does

  • Every trade is one bracket order: an entry, a stop-loss and a take-profit target, sized from your risk profile.
  • Default profile: at most 3x leverage, 1% of equity at risk at the stop, one position at a time.
  • Orders under 2R are refused, and so is a stop outside half the distance to liquidation.
  • Desk briefs for crude oil (Brent and WTI) and metals (gold and silver) on Hyperliquid's HIP-3 markets give Claude a written call to trade from.
  • Claude Code asks before each live-money call. Nothing trades in the background.

Free

pathiel charges no fee: no order it places carries a Hyperliquid builder fee, so you pay only Hyperliquid's own trading fee.

Research pool

Opt in with one signed statement and pathiel grades your public fills with the same fluke-or-edge harness it runs on its own trades. Results are published at least 24 hours late on the scoreboard. No payout or reward is tied to returns.

Risk

Leveraged perps can lose the whole account, fast. There is no demonstrated edge and no return is promised. This is software, not financial advice. Hyperliquid's terms bar use from restricted jurisdictions, including by US persons; pathiel does not check where you are.
