# contracts/strategies

The desk contract. A desk is one siloed focus (oil, btc, top5, ai, ...) with its
own instruments, news queries, policy topics, catalysts, token budget and
thesis journal.

| model | produced by | space |
|---|---|---|
| `DeskSpec` | `services/strategies/desks/*.py` registry | config |
| `DeskAnalytics` | `services/strategies` | deterministic |
| `IntelPacket` | `services/intel` | deterministic fetch + scoring |
| `Thesis` | `services/thesis` via `services/llm` | latent, validated |
| `Grade` | `services/strategies` grader | deterministic |
| `DeskCard`, `DeskBrief`, `RefreshJob` | `services/strategies/api.py` | HTTP |

Routes are listed at the bottom of `models.py`.

Fixtures in `fixtures/` are the real oil read of 2026-10-17 and are generated by
`python -m contracts.strategies.fixtures._build`. Every consumer tests against
them. Change a model, regenerate, bump `CONTRACT_VERSION` if it breaks a reader.
