# MCP tool table

`scripts/pathiel-mcp-server.py` serves two tool lists over stdio. A public install (the plugin, Dockerfile.mcp, MCP directories) lists the 30-tool public toolset (contracts/mcp_public): verb_noun names, one tool per job. The operator's install (.mcp.json, the live desks) lists the 60 tools further down. Every name in either list stays callable on both installs. Generated by `scripts/mcp_tool_table.py`; do not edit by hand.

LIVE-MONEY tools (never call outside a mocked test): **bracket_sweep**, **cancel_order**, **close_position**, **place_bracket**, **set_leverage**, **set_stop**, **set_target**.

Every tool carries MCP annotations (readOnlyHint / destructiveHint). Live smoke over the real transport: `.venv/bin/python scripts/mcp_smoke.py`. Description quality: `.venv/bin/python scripts/tdqs_eval.py`.

| `place_bracket` | LIVE MONEY | `place_bracket` | LIVE MONEY: acts on the real account.
