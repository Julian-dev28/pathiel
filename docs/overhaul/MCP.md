# MCP tool table

`scripts/pathiel-mcp-server.py`: 81 tools over stdio. Generated by `scripts/mcp_tool_table.py` from the server's TOOLS and ALIASES; do not edit by hand.

LIVE-MONEY tools (never call outside a mocked test): **bracket_sweep**, **cancel_order**, **close_position**, **execute**, **place_bracket**, **set_leverage**.

Every tool carries MCP annotations (readOnlyHint / destructiveHint). Live smoke over the real transport: `.venv/bin/python scripts/mcp_smoke.py`.

## Start here: desks, account, risk

| tool | safety | also answers (hidden aliases) | description |
|---|---|---|---|
| `desk_list` | read-only |  | Every desk's one-line card: tagline, primary coin, mid, 1d return, latest call and track record. Start here before desk_brief. |
| `desk_brief` | read-only |  | One desk's current call. mode=quick (default): short markdown, the call first, plus "Your size" for the active account. mode=full: the whole structured brief (analytics, intel, thesis, history). |
| `desk_refresh` | writes journal |  | Refresh a desk: market data, news/policy/odds, then a NEW thesis via the local model (~1 min; progress reported). Skips the model unless the market moved, a big headline landed, the thesis expired, or force=true. |
| `desk_submit_call` | writes journal |  | Record your own trade call on a desk (author=user), journaled alongside the machine's theses for track-record comparison. |
| `desk_track_record` | read-only |  | Graded-thesis track record for one desk: hit rate, mean Brier, mean return, split machine vs user calls. |
| `desk_grade` | writes journal |  | Grade now: expired theses, then accounts' trades vs each call. desk narrows trade grading only. |
| `account_overview` | read-only |  | The active account's money: total equity, where it sits (each perp dex incl. HIP-3, plus spot), open positions, and whether it can trade right now (plain-English blockers). Start here for "how much do I have". |
| `accounts` | read-only |  | Hyperliquid accounts registered in pathiel (connected wallets, API keys, watch-only), which one is active, and which address the bot trades with. Connect or switch in the dashboard's Account tab. |
| `risk_limits` | read-only |  | What the account may trade under its risk profile: positions at once, $ lost per stop-out, daily pause, max leverage. equity_usd/preset = what-if. |
| `risk_size_trade` | read-only |  | Size ONE trade for the active account: size, margin, $ at risk, payoff per target, liquidation price. Same rules as the bot's books. Use it before suggesting any size. |
| `place_bracket` | LIVE MONEY |  | LIVE MONEY: acts on the real account. One trade with exact stop and take-profit, sized like risk_size_trade. entry_px = resting limit, stop/target attached on fill; omit for market. Refuses under min_r (1.5R) or an existing position/entry on the coin. dry_run = size only. |
| `bracket_sweep` | LIVE MONEY |  | LIVE MONEY: acts on the real account. Flat: cancel leftover reduce-only orders (sibling of a fired stop/target), list resting entries. In a position: say whether a stop covers it. Never opens or closes. |

## Agent loop and live-money actions
