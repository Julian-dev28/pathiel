pathiel research pool scoreboard

This page shows graded results of pathiel research pool members' public Hyperliquid fills. Hyperliquid already makes fills public; nobody uploads anything here.

Graded results of public fills, at least 24 hours late. Not live positions, not advice.

No edge is demonstrated until a row with 10 or more independent trades says EDGE.

Pool rows count independent trades: trades on the same coin and side entered within 24 hours of the first one count once.

Rows are ordered by number of graded trades, not by result.

To join, run /pathiel:share in the pathiel Claude Code plugin. Project and source: github.com/Julian-dev28/pathiel.
