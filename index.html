pathiel is a free, open-source Hyperliquid MCP server and Claude Code plugin: 30 tools for Claude Code, Claude Desktop, Cursor, or any MCP client.

Install Scoreboard

Real money. pathiel runs on Hyperliquid mainnet. With no key it only reads; once you add a key, orders are real. Practice on testnet with one line: PATHIEL_NETWORK=testnet.

How it works

  1. Research. No account, no key. Market data, order books, funding, and desk briefs with a written call.
  2. Connect. One signature connects your Hyperliquid wallet: it approves an API wallet, which can trade and never withdraw.
  3. Trade. Every trade is one bracket order: an entry, a stop-loss and a take-profit target, sized from your risk profile.

Install, in Claude Code

/plugin marketplace add Julian-dev28/pathiel
/plugin install pathiel@pathiel
/pathiel:setup

Setup shows the network and the risks, builds a private Python environment, and connects the MCP server. Works with Claude Code, Claude Desktop, Cursor and any MCP client.

Desk briefs

Oil · Metals · S&P 500 · HYPE

Each desk gives Claude a written call: direction, entry, stop, target, and the catalyst that would change its mind. Nothing trades unless you ask.

Risk, enforced on every order

Order shape
Every trade is one bracket order: an entry, a stop-loss and a take-profit target, sized from your risk profile.
Default profile
At most 3x leverage, 1% of equity at risk at the stop, one position at a time.
Minimum reward
At least 2R, or the order is refused.
pathiel fee
pathiel charges no fee: no order it places carries a Hyperliquid builder fee, so you pay only Hyperliquid's own trading fee.

Research pool

Opt in with one signed statement. pathiel grades your public fills with the same harness it runs on its own trades, and publishes them at least 24 hours late.
