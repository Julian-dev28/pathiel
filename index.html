Overviewv0.7.1
Claude Code · MCP · Hyperliquid

An AI trading agent for Hyperliquid: Claude trades perps from Claude Code, with an exact stop and target on every order.

pathiel is a free, open-source Hyperliquid MCP server and Claude Code plugin: 30 tools that read Hyperliquid perpetual futures markets and your account, and place orders, from Claude Code, Claude Desktop, Cursor or any MCP client.

Install Scoreboard

Real money. pathiel runs on Hyperliquid mainnet. With no key it only reads; once you add a key, orders are real. Practice on testnet with one line: PATHIEL_NETWORK=testnet.

InstallClaude Code3 lines
/plugin marketplace add Julian-dev28/pathiel
/plugin install pathiel@pathiel
/pathiel:setup

Setup shows the network and the risks, builds a private Python environment and connects the MCP server.

Reading markets needs no account. To trade, connect your Hyperliquid wallet with one signature: it approves an API wallet, which can trade and never withdraw.

Order shapeBRACKETEvery trade is one bracket order: an entry, a stop-loss and a take-profit target, sized from your risk profile.
Risk at the stop1.00%Default profile: at most 3x leverage, 1% of equity at risk at the stop, one position at a time.
